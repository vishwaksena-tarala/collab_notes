CollabNotes

A real-time collaborative note-taking platform where teams create, edit, and share Markdown notes simultaneously — with live synchronisation, version control, and rich media support.

React 18 Spring Boot 3.2 MongoDB Socket.IO JWT Auth Markdown

Built with ❤️ · Full-Stack Collaborative Web Application

01 · Introduction

What is CollabNotes?

🔍

The Problem

Traditional note-taking tools are siloed and single-user. Teams struggle to collaborate without constant manual file sharing, merge conflicts, and outdated copies.

💡

Our Solution

CollabNotes provides a web-based workspace where multiple users edit notes simultaneously in real-time — with automatic saving, live presence indicators, and organised folders.

🎯

Target Audience

Students, research teams, developers, and professionals who need a lightweight but powerful shared workspace for knowledge management.

🌐

Platform

Fully browser-based web application. No installation needed. Access from any device with secure JWT authentication and persistent cloud storage via MongoDB.

02 · Uniqueness

What Makes It Stand Out?

1

Live Collaboration with Presence Awareness

Real-time note syncing via Socket.IO with animated typing indicators and avatar badges showing exactly who is currently editing — no refresh needed.

2

Integrated Drawing Canvas → Markdown Image

Unique in-browser freehand drawing tool that auto-uploads the canvas as a PNG and inserts it directly as a Markdown image into the note — no external tool required.

3

Version History with One-Click Restore

Every save creates a timestamped version snapshot. Any collaborator can browse the history and instantly restore to any previous version, preserving who saved it.

4

Drag-and-Drop File Embedding

Users can drag images or PDFs directly onto the editor — they're automatically uploaded to the server and embedded as Markdown links or images, no copy-paste needed.

04 · Features

Core Features

⚡

Real-Time Collaboration

Multiple users edit simultaneously. Typing indicators show when peers are writing. Active user avatars displayed live in the toolbar.

📝

Markdown Editor (Split View)

Write, Split, or Preview modes. Syntax-highlighted Markdown with GitHub Flavoured Markdown (GFM) tables, checkboxes, code blocks.

🕒

Version History

Every save creates a snapshot with timestamp and author. Any version can be restored in one click via a slide-in history drawer.

📁

Folder Organisation

Create, rename, and delete folders. Notes can be moved between folders. Sidebar navigation with instant filter and search.

🎨

Drawing Canvas

Full-screen freehand canvas with colour palette, brush size, eraser, and undo. Drawings auto-upload and insert into the note as images.

🖼️

Image Gallery & File Upload

Browse previously uploaded images in a modal gallery. Drag-and-drop images or PDFs directly onto the editor to embed them instantly.

🔗

Note Sharing

Share any note with other users by username or email. Fine-grained owner vs collaborator access control — only owners can share.

🔐

Secure Authentication

BCrypt password hashing, JWT with 7-day expiry, auto-redirect on 401. All API endpoints protected by Spring Security filter chain.

💾

Autosave

1.5-second debounced autosave triggers after every keystroke. A green checkmark confirms the last saved time without interruption.
